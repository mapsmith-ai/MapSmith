# MapSmith 0.11.0 Release Hardening Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close the pre-release findings and publish MapSmith 0.11.0 with verified artifacts on every supported channel.

**Architecture:** Centralize derived-sidecar containment and atomic writes in `workspace.py`. Reserve dataset and sidecar paths during plan validation and repair, then address the remaining behavior and documentation findings without changing the public tool contracts.

**Tech Stack:** Python 3.12+, pytest, GeoPandas, Rasterio, Pydantic, GitHub Actions, PyPI, GHCR, MCP Registry, Zenodo.

**Spec:** `CHANGELOG.md`, `AGENTS.md`, and the independent pre-release reviews of `v0.10.1..547881b`.

## Global Constraints

- Public code, tests, comments and commit messages are in English.
- Every writer preserves provenance and writes its audit record before enforcement.
- Workspace-confined reads and writes must not follow derived sidecars outside the workspace.
- Do not execute arbitrary model-written repair code; repair remains bounded to three attempts.
- No production change without a failing regression test first.
- No tag until the full suite, Ruff, independent reviews and release pre-flight checks are green.

## Review Focus

- A sidecar symlink targeting an external JSON file must be refused on read and must not be overwritten on write; Task 1.
- An output named like another step's `.plan.json` or provenance file must be refused before execution; Task 2.
- A malformed repair manifest section must produce `INVALID_REPAIR_CHAIN`, not `AttributeError`; Task 4.
- Geometries disjoint from the reference grid must produce a background raster with a warning, not silent success; Task 3.
- An unknown spatial-join engine must not produce an install command for an invented extra; Task 4.
